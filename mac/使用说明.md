# 斐讯遥控器 → Mac 无线麦克风

把斐讯 N1/BD1-R 蓝牙语音遥控器当成 Mac 的麦克风用：按住遥控器的语音键说话，
声音会被推入虚拟声卡 **BlackHole 2ch**，任何语音输入法（闪电说、系统听写等）
把它当麦克风选上就能直接听写。

## 一次性准备

1. 装 BlackHole 2ch：`BlackHole2ch-0.7.1.pkg`（放在本目录的上一级，双击安装；
   也可从 <https://existential.audio/blackhole/> 下载，sha256 应为
   `57b540f27a3e29c37e310e01bee0fdfab76733087e47f997ef9dccf851400dcf`）。
2. 遥控器蓝牙配对一次：按住 **主页 + 音量-** 进配对，用系统蓝牙设置连上
   （配对键各批次可能不同，能连上就行；之后每次按任意键就会自动重连）。
3. 首次运行会请求两个权限，都授给 **「斐讯遥控器麦克风」这个 App**：
   - **蓝牙**
   - **辅助功能**（拦截遥控器 F5 连发、合成听写按键；系统设置 → 隐私与安全性 → 辅助功能）
   从旧版 `.command` 升级来的，Terminal 的那条授权对这个 App 不算数，要重新加一次。

## 日常使用

1. 双击 `斐讯遥控器麦克风.app`（不经过终端，不会弹终端窗口）。
2. 点 **连接**（遥控器休眠时按任意键唤醒）。
3. 在语音输入法里把麦克风设成 **BlackHole 2ch**。
4. 按住遥控器语音键说话，松开即结束。

「语音键联动」打开后，程序会在你有声音时**按住**所选的听写快捷键、说完（静音 0.35 秒）**松开**，
你就不用再摸键盘。默认键是**右 Shift**，听写工具里也设成右 Shift 即可。

闪电说这类工具是**长按说话**模式（按住时录音、松开即出字），所以这里必须是"按住/松开"而不是点一下；
2026-11-03 之前版本发的是不带修饰键 mask 的瞬时点按，闪电说收不到（日志里只有 FlagsChanged 才算数），已修。

手动使用时也可以不开联动：自己按住右 Shift 说话，效果一样，只是要占一只手。

## 录音与排错

- **测试输入**：录 5 秒并自动回放，用来确认声音真的进来了。
- 录音都在 `recordings/`，可"打开录音文件夹"直接听。
- 日志：`remote-mic.log`。
- 命令行自检（不弹界面）：`./venv/bin/python remote_mic_mac.py --selftest 5`
- 连不上：先按一下遥控器任意键唤醒，再点连接；仍不行就重新配对一次。
- 没有声音：确认听写工具的麦克风是 BlackHole 2ch；BlackHole 设备名必须是 `BlackHole 2ch`。

## 原理（协议）

语音走 Kehwin 私有 BLE 协议，不是小米遥控器那套 Google ATVV：

- 服务 `0x1920`，写 `2B01`，通知 `2B00`
- 握手：`[08 01]+rand32(LE)+[01 03]+12×00` → `[08 0C]+4×00+[01]+13×00`
- 开流 `[08 06 01]+17×00`，停流 `[08 06 00]+17×00`
- 音频：120 字节通知包 = 2 个 60 字节 mSBC 帧，16 kHz 单声道，7.5 ms/帧
- 解码：`ffmpeg -f sbc` → 48 kHz 立体声 → BlackHole

macOS 侧要点：`bleak` 看不到"已连接但不广播"的设备，必须用 CoreBluetooth 的
`retrieveConnectedPeripheralsWithServices`；并且回调要走 GCD 队列，
否则和图形界面抢主线程会让音频断续。

## 环境要求（2026-11-03 补充）

运行环境已固定为仓库内 `venv/`（Python 3.12.14 + Tk 9.0），双击启动器会用它，不用管。

- **不要**用系统自带的 `/usr/bin/python3`（3.9，Tk 8.5）重建 venv：在 macOS 27 上 Tk 8.5 画不出 `ttk` 控件和标签，
  窗口会是一片空白（只剩标题栏）。重建请用 `/Volumes/Data/Agent/.system/runtime/Python/bin/python3`（3.12）：
  `python3 -m venv venv && ./venv/bin/pip install -r requirements.txt`。
- 旧的 3.9 环境保留在同目录 `venv-py39-legacy/`，仅在需要对比时用，正常不用；确认无用可整个删掉（省 67 MB）。

## 关于遥控器的 F5（2026-11-03 补充）

遥控器的语音键在系统里还同时是一只键盘的 **F5**。按住语音键时 macOS 会以约 12 次/秒自动连发 F5，
听写工具会误以为你在打字，从而把程序合成的右 Shift 判成"卡键"清掉 —— 表现为录音 0.7 秒就断、转不出字。

程序现在会自动吞掉这类 F5 连发（只在程序运行时、只吞硬件来源的 F5）。开关在 `config.json` 的
`guard_remote_f5`（默认 true）。**开着的时候，你键盘上的 F5 也不会生效**；需要用 F5 就把这个开关设成 false。
