# 斐讯遥控器麦克风 · 使用说明

把斐讯 DB1-R 蓝牙遥控器变成 Windows 上的无线麦克风：遥控器按住语音键说话，
声音进入虚拟声卡 `CABLE Output`，任何 AI 应用（微信、豆包、Codex 等）选它当麦克风即可。
音频只在本机转发，不上传、不联网。

## 一、安装（只需一次）

1. **装 VB-CABLE 虚拟声卡**：从官网 https://vb-audio.com/Cable/ 下载 VBCABLE_Driver_Pack，
   右键“以管理员身份运行”安装，安装完按提示重启或注销。装好后系统里会多出
   `CABLE Input`（本工具往里送声音）和 `CABLE Output`（应用把它当麦克风）两个设备。
2. **装 Python 3.11 或更高版本**（安装时勾选 Add python.exe to PATH）。
3. **装 FFmpeg 并加入 PATH**（解码遥控器的 mSBC 音频要用）。
4. **装 Python 依赖**，两种方式任选其一：
   - `pip install -r requirements.txt`（在仓库根目录执行）；
   - 或沿用原型的便携方式：把依赖包放进 app 目录下的 `deps\` 文件夹
     （工具启动时会自动优先使用 deps 里的包，不污染全局 Python）。

## 二、启动与连接

1. 双击 **启动遥控器麦克风.cmd**（若报缺 Python/依赖，窗口会停住显示报错，不会一闪而过）。
2. 按遥控器任意**方向键**唤醒它（唤醒后才能被蓝牙连上）。
3. 点窗口里的 **连接**：
   - 首次连接会自动从**系统已配对设备清单**里找到斐讯遥控器（遥控器休眠也能找到，无需广播）；
   - 连接成功后地址会保存到 `config.json`，以后直接用；
   - 只有从未配对过的新遥控器才会走蓝牙扫描（需长按 主页+音量- 进入配对模式）；
   - 也可手动指定地址：`启动遥控器麦克风.cmd --addr 00:E0:4C:2C:04:B6`。
4. 状态栏显示“已连接”即就绪。按住遥控器**语音键**说话，松开结束。

## 三、测试输入（验证整条链路）

连接成功后，**测试输入**按钮会变为可用：

1. 点 **测试输入**，状态栏倒计时 5 秒——这期间**按住遥控器语音键说话**。
2. 倒计时结束后自动停止，工具会把刚刚经虚拟声卡回环的声音存成
   `app\recordings\test-日期-时间.wav`（48kHz 立体声），并自动用默认扬声器回放。
3. 窗口里的**录音列表**会刷新，显示每个文件的文件名和时长（秒）；
   点 **打开录音文件夹**可直接打开目录查看。
4. 听到自己的声音 = 蓝牙、解码、虚拟声卡整条链路正常。测试期间主推流不中断。

## 四、在应用里选择麦克风

在 AI 应用的麦克风（录音/语音输入）设置里，选择 **CABLE Output**——
不是 CABLE Input。窗口底部常驻提示同款文字；点 **打开声音设置**可直接打开
Windows 声音控制面板核对。多数应用会记住设备；网页若只给“默认麦克风”，
需在 Windows 或浏览器里把默认输入设备指定为 CABLE Output。

## 五、配合闪电说等听写输入法（语音键联动）

1. 在闪电说里选 **「按一次开始、再按一次结束」** 模式，语音快捷键绑定 **左 Alt**，
   麦克风选 **CABLE Output**。
2. 本工具勾选 **「语音键联动（按住说话自动开关听写）」**，听写快捷键保持 **左Alt**。
3. 按住遥控器语音键说话：首个有效音频包触发一次点按，听写开始；
   松开后约 **0.35 秒**（按最后一个有效包计时）自动再点按一次，听写结束。

快捷键必须区分左右：闪电说设「右Shift」，本工具也必须显示「右Shift」。
旧版将左右 Shift 错存为通用 Shift（实际发出左 Shift），已修复；旧 Shift 配置请重新录制。
「直接选键」下拉菜单可明确选择左右 Shift/Alt/Ctrl 或 F9，无需录制，
适合已有全局快捷键拦截录制的情况。「自定义…」仍可录制单键或组合键；
如果读到了输入法处理键，会提示切换英文输入法后重试。

**联动自检**：断开遥控器连接后点击，会自动发送开始/结束两次快捷键，
用 `GetAsyncKeyState` 高位检查系统是否观察到全部按键。请同时观察闪电说是否开始并结束。
系统可见只证明按键进入系统状态；系统不可见也不能断定未触发，听写工具的钩子可能
先处理按键再拦截系统传播。请以实际录音开始/结束为准；无反应时核对快捷键绑定、模式和权限。

开启/关闭复选框立即生效并保存。关闭联动、停止、断连或关闭窗口时，
如果本工具已开始听写，会用开始时的快捷键补一次结束，避免停留在收音状态。
听写中修改快捷键也会用原键收尾，下次讲话使用新键。
仅在联动模式下让本工具控制开始/结束，期间手动切换听写会使 toggle 状态失配。
长按式听写工具请关闭联动。

## 六、FAQ

| 现象 | 原因与处理 |
| --- | --- |
| 找不到 CABLE Output / 提示找不到 VB-CABLE | 没装 VB-CABLE 虚拟声卡，按第一节安装并重启。 |
| 连不上 / 扫不到遥控器 | 遥控器在休眠，按**方向键**唤醒后重试；仍不行就 `--addr` 手动指定地址。 |
| 声音断续、卡顿 | 蓝牙距离太远或 2.4G 干扰（路由器、USB3 设备），靠近电脑、减少中间障碍。 |
| 应用里没声音 | 确认应用选的是 **CABLE Output** 而不是 CABLE Input；再点“测试输入”确认链路正常。 |
| 听写工具不停开始/结束错乱 | 语音键联动与长按式工具不兼容，关闭「语音键联动」复选框。 |
| 启动窗口一闪而过 | 用 .cmd 启动；报错时窗口会 pause 停住，按提示装 Python/依赖/FFmpeg。 |
| 已经打开了一个窗口 | 工具是单实例的，第二次启动会提示“工具已经打开”。 |

## 七、隐私与文件

- 音频只在本机转发；程序不上传、不联网。
- `app\recordings\` 里的测试录音是你点“测试输入”时主动录制的，可随时删除。
- `remote-mic.log` 记连接、快捷键配置和联动开始/结束（时间、VK、包数、解码字节数），
  不记音频内容；自动限制大小（256KB×2）。
- `config.json` 保存遥控器地址、听写快捷键和语音键联动开关；删掉即恢复默认左Alt（重新按系统清单/扫描查找）。
- 不再使用：关窗口即可；虚拟声卡可在“已安装应用”里单独卸载 VB-CABLE。
